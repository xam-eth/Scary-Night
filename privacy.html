PRIVACY POLICY

LAST NIGHT · kebijakan privasi · berlaku untuk build web dan build Google Play.

This page is the privacy policy for the game LAST NIGHT. It is also linked inside the game (menu and Settings) and is the URL to paste into Play Console.

SIAPA YANG MENANGANI DATA

Pengembang game LAST NIGHT. Pertanyaan privasi: buka isu di repositori publik game, atau email dukungan yang tercantum di listing Play Console. Jangan kirim Server Key, bukti pembayaran lengkap, atau sandi.

Privacy contact: the Play Console support email, or a public issue on the game repository. Do not send payment secrets.

APA YANG TIDAK KAMI AMBIL

  • Tidak ada akun. Tidak ada email, nama, nomor telepon, atau kata sandi.
  • Tidak ada lokasi, kontak, foto, mikrofon, atau daftar aplikasi.
  • Tidak ada iklan, dan tidak ada ID iklan (GAID) yang dibaca game ini.
  • Tidak ada analitik pihak ketiga.

No account, no ads, no location, no contacts, no advertising ID, no third-party analytics.

APA YANG TERSIMPAN DI PERANGKAT

Progres (malam yang selamat, pecahan darah, pengaturan, item yang sudah dibeli) disimpan di perangkat ini, di localStorage, kunci lastnight.save.v1. Data itu tidak dikirim ke server kami kecuali kamu sendiri membayar lewat web.

Progress stays on the device. It is not uploaded unless you start a web payment.

PEMBAYARAN

Google Play. Barang digital (satu belas kasihan, mantel, nama Dawnbreaker) di aplikasi yang diunduh dari Play wajib dibayar lewat Google Play Billing. Pecahan darah tidak dijual. Itu syarat Kebijakan Pembayaran Google Play. Midtrans tidak dipakai untuk barang digital di build Play. Google memproses pembayaran itu menurut kebijakan Google.

Web. Di browser, pembayaran memakai Midtrans Snap (QRIS, GoPay, transfer bank). Merchant ID M769336744. Saat kamu menekan bayar, game membuat id acak di perangkat (lastnight.playerId) dan mengirim id itu plus kode barang ke server kami, yang membuat transaksi di Midtrans. Server key tidak pernah ada di aplikasi. Hibah item hanya setelah server mengonfirmasi settlement.

Play builds bill digital goods only through Google Play Billing. The browser build uses Midtrans. The server key never ships in the app. A random on-device id is sent only when you pay on the web.

BERBAGI DENGAN PIHAK LAIN

  • Midtrans, hanya untuk pembayaran web yang kamu mulai.
  • Google Play, hanya untuk pembelian di build Play.
  • Tidak dijual. Tidak dipakai untuk iklan.

ANAK-ANAK

LAST NIGHT adalah horror untuk 18 tahun ke atas. Bukan untuk anak. Tidak ikut Google Play Families. Jangan mainkan jika kamu di bawah 18.

18+ horror. Not directed at children. Not in the Families program.

KEAMANAN DAN RETENSI

Lalu lintas pembayaran memakai HTTPS. Data di perangkat tetap ada sampai kamu menghapusnya. Catatan pembayaran web di server dihapus saat kamu meminta penghapusan. Kami tidak membekukan data sebagai pengganti penghapusan. Jika hukum mewajibkan menyimpan bukti transaksi, yang disimpan hanya catatan akuntansi minimum, dan hanya selama wajib, lalu dihapus.

HAPUS DATA

Di dalam game: Settings atau layar Privacy → DELETE MY DATA. Itu menghapus simpanan di perangkat dan meminta server menghapus catatan pembayaran untuk id perangkat itu.

Tanpa membuka game: halaman hapus data. Karena tidak ada akun, kamu memasukkan id perangkat yang terlihat di layar Privacy. Mengosongkan data aplikasi di Android juga menghapus salinan lokal.

In-app: Privacy → Delete my data. On the web, without reinstalling: the deletion page. Clearing app storage on Android deletes the local copy.

DATA SAFETY (PLAY CONSOLE)

Jawaban yang sesuai dengan build ini ada di docs/PLAY-STORE.md. Jika suatu hari iklan dinyalakan, kebijakan ini dan formulir Data safety harus diubah dulu. Sekarang: Contains ads = No.
