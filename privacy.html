Bahasa Indonesia

Kebijakan ini menjelaskan data yang diproses DUSKHOLD pada build web dan Google Play.

Pengembang dan pengendali data

Pengembang dan pengendali data: Jamadianur (publishing as Zyvro Labs), Rantau, Kalimantan Selatan, Indonesia.

Pertanyaan atau permintaan privasi: jamadianur@zyvrolabs.com.

Repositori GitHub publik dapat digunakan sebagai jalur tambahan: issues DUSKHOLD. Jangan kirim kata sandi, kunci server, atau data pembayaran lengkap.

Data yang dikumpulkan

DUSKHOLD tidak membuat akun dan tidak meminta nama, email, nomor telepon, lokasi, kontak, foto, mikrofon, atau daftar aplikasi. Game tidak membaca ID iklan dan tidak menggunakan analitik pihak ketiga.

Progres dan pengaturan disimpan secara lokal di perangkat melalui localStorage, termasuk kunci lastnight.save.v1. Data tersebut tidak dikirim ke server kecuali kamu memulai pembayaran web.

Pembayaran dan pihak yang menerima data

  • Google Play: pembelian digital dalam build Google Play diproses oleh Google Play Billing dan tunduk pada kebijakan Google.
  • Web: pembayaran yang kamu mulai diproses oleh Midtrans Snap. Server menerima ID perangkat acak (lastnight.playerId) dan kode barang untuk membuat serta mencatat transaksi. Merchant ID: M769336744. Kunci server tidak dikirim ke aplikasi.

Data pembayaran hanya dibagikan kepada Google Play untuk pembelian dalam build Play dan kepada Midtrans untuk transaksi web yang kamu mulai. Data tidak dijual dan tidak digunakan untuk iklan.

Retensi dan keamanan

Lalu lintas pembayaran menggunakan HTTPS. Data lokal tetap berada di perangkat sampai dihapus. Catatan transaksi web disimpan di server dan dikaitkan dengan ID perangkat.

Belum untuk dipublikasikan: pemilik belum mengonfirmasi berapa lama catatan transaksi web dan catatan akuntansi yang diwajibkan hukum disimpan. Periode retensi yang tepat harus ditetapkan sebelum kebijakan ini diterbitkan; tidak ada durasi yang ditebak di sini.

Penghapusan data

Di dalam game, buka Settings → Privacy → DELETE MY DATA. Tindakan ini menghapus progres lokal dan mengirim permintaan untuk menghapus catatan pembayaran server bagi ID perangkat tersebut. Menghapus penyimpanan aplikasi di Android menghapus salinan lokal, tetapi tidak dengan sendirinya mengirim permintaan penghapusan catatan web.

Untuk meminta penghapusan tanpa membuka game, gunakan halaman penghapusan data. Jika ID perangkat hilang atau tidak dapat diakses, email jamadianur@zyvrolabs.com. Jangan sertakan kredensial pembayaran lengkap.

Waktu pemrosesan: batas waktu pemrosesan permintaan belum dikonfirmasi oleh pemilik dan tidak dijanjikan di halaman ini.

Anak-anak

DUSKHOLD adalah game horor untuk pemain dewasa (18+) dan tidak ditujukan untuk anak-anak.

English

This policy explains the data processed by DUSKHOLD in the web and Google Play builds.

Developer and data controller

Developer and data controller: Jamadianur (publishing as Zyvro Labs), Rantau, South Kalimantan, Indonesia.

Privacy questions or requests: jamadianur@zyvrolabs.com.

The public GitHub repository is an additional contact route: DUSKHOLD issues. Do not send passwords, server keys, or full payment credentials.

Data collected

DUSKHOLD does not create accounts or ask for your name, email address, phone number, location, contacts, photos, microphone, or installed-app list. The game does not read an advertising ID or use third-party analytics.

Progress and settings are stored locally on your device through localStorage, including the lastnight.save.v1 key. This data is not sent to our server unless you start a web payment.

Payments and data recipients

  • Google Play: digital purchases in the Google Play build are processed by Google Play Billing and are subject to Google’s policies.
  • Web: payments you initiate are processed by Midtrans Snap. Our server receives a random device ID (lastnight.playerId) and item code to create and record the transaction. Merchant ID: M769336744. The server key is not sent to the app.

Payment data is shared with Google Play for purchases in the Play build and with Midtrans for web transactions you initiate. It is not sold or used for advertising.

Retention and security

Payment traffic uses HTTPS. Local data remains on your device until deleted. Web transaction records are stored on the server and linked to the device ID.

Not ready for publication: the owner has not confirmed how long web transaction records and legally required accounting records are kept. The exact retention periods must be set before this policy is published; no duration is guessed here.

Data deletion

In the game, go to Settings → Privacy → DELETE MY DATA. This removes local progress and sends a request to delete server payment records associated with that device ID. Clearing Android app storage removes the local copy, but does not by itself send a request to delete web records.

To request deletion without opening the game, use the data deletion page. If you lost or cannot access the device ID, email jamadianur@zyvrolabs.com. Do not include full payment credentials.

Processing time: the owner has not confirmed a processing deadline, so none is promised on this page.

Children

DUSKHOLD is an adult (18+) horror game and is not directed at children.
