# Environment kit — KayKit Dungeon Remastered (CC0)

Modular gothic-dungeon 3D pieces for the `LAST NIGHT` mansion (Environment
2.5D→3D, epic #53 / Phase C). A curated 21-piece starter set of the full pack.

- **Source:** KayKit — Dungeon Remastered 1.0, by Kay Lousberg (www.kaylousberg.com)
- **Upstream:** https://github.com/KayKit-Game-Assets/KayKit-Dungeon-Remastered-1.0
- **License:** Creative Commons Zero (CC0 1.0) — free for personal, educational and
  **commercial** use; attribution appreciated but not required. Full text upstream
  (`LICENSE.txt`). Credit: Kay Lousberg, www.kaylousberg.com.
- **Format:** binary glTF (`.glb`), self-contained (textures embedded), stylized low-poly.

Files were copied from the pack's `Assets/gltf/` and renamed to clean, URL-safe
names. Total ~1.2 MB. The full 203-piece pack has more variants if the kit needs
extending (walls, floors, furniture, props, stairs, banners, etc.).
