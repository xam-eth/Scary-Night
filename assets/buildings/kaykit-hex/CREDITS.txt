Fetched 2026-10-17 through the GitHub API for the build-plot pass (playtest:
"bangunan yg di build belum memakai asset visual yg layak dan tepat masih
berupa prototype"). Every file below is vendored byte-for-byte for runtime use
(not re-exported or modified); each one's git blob hash was checked against the
upstream tree at the commit above. The upstream folders are flattened into this
one directory: every .gltf references its .bin and hexagons_medieval.png by a
bare file name, and the atlas is the same file (git blob 14cdc253) in every
upstream folder. Survival builds its buildings from these at runtime
(src/game/buildings3d.js, src/game/world3d.js); the blue team colour matches
the keep's royal-blue livery. Ghosts (what a plot will build) are runtime
material swaps on clones; the files stay as shipped.

2026-10-17, BUILD 11 (playtest: "tidak tau build yg mana" — which building is
which): every building type now has its own colour from the same pack, the
upstream colour variants of the same models (same atlas, other UVs): BARRACKS
blue, GOLD MINE yellow, SAWMILL green, BALLISTA red. The blue mine, lumbermill
and tower base were removed; their yellow / green / red twins were fetched
from the same commit, blob hashes checked the same way.
