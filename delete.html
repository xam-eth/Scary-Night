HAPUS DATA SAYA

LAST NIGHT tidak membuat akun. Progres ada di perangkat. Id pembayaran, jika pernah dibuat, terlihat di layar Privacy di dalam game (bentuknya LN-……).

This game does not create an account. Local progress is deleted by clearing the app’s storage, or with Delete my data inside the game. This page deletes the web payment ledger for the on-device id, without reinstalling.

  1. Di Android: Setelan → Aplikasi → LAST NIGHT → Hapus data. Itu menghapus simpanan lokal.
  2. Untuk catatan pembayaran web, masukkan id perangkat di bawah. Penghapusan bersifat permanen, bukan pembekuan.
