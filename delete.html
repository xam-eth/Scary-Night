Hapus Data Saya / Delete My Data

Terakhir diperbarui / Last updated: tanggal merge PR akan diisi sebelum publikasi / the PR merge date will be added before publication.

Bahasa Indonesia

Pengembang: Jamadianur (publishing as Zyvro Labs), Rantau, Kalimantan Selatan, Indonesia. Kontak privasi: jamadianur@zyvrolabs.com.

DUSKHOLD tidak membuat akun. Halaman ini meminta penghapusan catatan transaksi web yang terkait dengan ID perangkat; halaman ini tidak menghapus progres lokal di perangkat.

  1. Di dalam game: buka Settings → Privacy → DELETE MY DATA untuk menghapus progres lokal dan meminta penghapusan catatan server bagi ID tersebut.
  2. Tanpa membuka game: masukkan ID perangkat yang digunakan saat pembayaran web, lalu kirim permintaan di bawah.
  3. Untuk menghapus progres lokal di Android tanpa game, buka Setelan → Aplikasi → DUSKHOLD → Hapus penyimpanan. Langkah ini tidak menghapus catatan transaksi web.

Format ID dan bantuan

ID biasa berbentuk LN- diikuti 8 huruf atau angka (A–Z, 0–9), misalnya LN-AB12CD34. Dalam mode penyimpanan privat, aplikasi dapat memakai ID fallback LN-WEB.

Jika perangkat atau ID hilang, email jamadianur@zyvrolabs.com dengan subjek “DUSKHOLD — permintaan penghapusan data”. Berikan informasi yang cukup untuk menemukan transaksi; jangan kirim kata sandi, kunci server, atau data kartu lengkap.

Masukkan ID untuk pembayaran web / Enter the ID used for web payment.

Contoh normal: LN- diikuti 8 huruf/angka; fallback: LN-WEB. / Normal: LN- plus 8 alphanumeric characters; fallback: LN-WEB.

English

Developer: Jamadianur (publishing as Zyvro Labs), Rantau, South Kalimantan, Indonesia. Privacy contact: jamadianur@zyvrolabs.com.

DUSKHOLD does not create accounts. This page requests deletion of web transaction records linked to a device ID; it does not erase local progress on the device.

  1. In the game: go to Settings → Privacy → DELETE MY DATA to clear local progress and request deletion of the server records for that ID.
  2. Without opening the game: enter the device ID used for the web payment and submit the request below.
  3. To clear local progress on Android without the game, open Settings → Apps → DUSKHOLD → Clear storage. This does not delete web transaction records.

ID format and help

A normal ID is LN- followed by 8 letters or digits (A–Z, 0–9), for example LN-AB12CD34. In private-storage mode, the app may use the fallback ID LN-WEB.

If you lost the device or ID, email jamadianur@zyvrolabs.com with the subject “DUSKHOLD — data deletion request”. Include enough information to identify the transaction; do not send passwords, server keys, or full card details.
